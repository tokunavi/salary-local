# 給与・税務（ローカル版）

給与明細の数字から、年間の所得税などの**目安**を出す Web アプリです（試作版・無料配布）。

- 入力したデータは、**お使いの端末の中だけ**に保存されます。このアプリは、入力内容を外へ送信しません（通信するのは、アプリ自身のファイルの読み込みだけです）。
- 配布元は、あなたの入力データを見ることができません。
- 令和8年（2026年）分に対応しています。

## 使い方

1. 配布された URL を、スマホやパソコンのブラウザで開きます（iPhone は Safari）。
2. 月ごとに、額面・手取り・保険料などを入れると、年間の見込みが出ます。
3. iPhone は、共有ボタンから「ホーム画面に追加」すると、アプリのように使えます。
4. **バックアップを取ってください。** 「ファイルに書き出す」で、iCloud Drive などに保存できます。ブラウザの設定や端末の状況によって、端末内のデータが消えることがあります。

- **概算の目安です。** 税務・法務・会計の相談ではなく、結果の正確さ・最新性は保証できません。実際の申告・手続きは、勤務先の年末調整、源泉徴収票、国税庁の案内などで確認してください。

- **個人の非営利の利用に限ります。** 再配布・販売・改変したものの公開はできません（許諾していません）。
- 招待された方向けの試作版です。予告なく内容の変更・提供の終了をすることがあります。
- 年ごとの制度の変更への対応は、遅れることや、行われないことがあります。
